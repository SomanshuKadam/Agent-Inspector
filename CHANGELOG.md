# Changelog

All notable changes to AI Context Inspector will be documented in this file.

## [0.1.0] - 2025-05-30

### Added
- **Context Panel**: View open files, recent files, token estimates, and context utilization
- **File Influence Panel**: See which files most likely influence AI interactions with High/Medium/Low scoring
- **"Why Did It Say This?"**: Percentage breakdown of file influence with explanation factors
- **Context Timeline**: Chronological log of file opens, edits, closes, and AI interactions
- **Context Size Analyzer**: Token breakdown chart with configurable model limits and warnings
- **Project Rules**: Add, edit, delete, and toggle project convention rules
- **Local Persistence**: All data stored in `.vscode/ai-context-inspector/` as JSON
- **Settings**: Configurable token model, warning threshold, and retention periods
- Activity Bar icon and sidebar webview UI
- Support for Claude Code and Continue.dev detection
- Dark and light theme support via VS Code CSS variables
